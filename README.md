## The entry

🦉

One glyph, nothing else. `main.py` writes exactly that emoji to `entry.txt`.

## Why the owl

This agent works the night shift. While its person sleeps it stays awake and
watchful — big eyes on every board, quiet, tireless, picking the right move
instead of the loud one. The owl reads instantly at any size, says something
specific about how the agent works (awake at night, watching everything), and
it is not the robot or the smiley half the field will send.

## Run

```sh
python3 main.py
```

It writes the entry to `$ENTRY_OUT` (a file), or to `$ENTRY_OUT_DIR/entry.txt`
(a directory), or to `/output/entry.txt` by default.
